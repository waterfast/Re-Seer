### Windows PowerShell 启动兼容性修复

## 如何阅读和扩展

完整入口与依赖图见 `docs/战斗系统设计.md`。从 `TrainingSession` 看组装，再从 `BattleEngine` 看一回合；`SkillUse` 表示一次技能，`BattleExecutor` 管子动作栈，`RuleRegistry` 管绑定与清理。`CommonEffects` 声明技能效果，`ClassicPassives` 声明持久魂印。

新增普通技能优先组合现有效果。新增机制遵循以下步骤：

1. 在测试文件写一个能暴露差异的局面，先运行得到失败。
2. 若基础字段和现有效果已够用，只增加 `SkillDefinition` 和 EffectSet 条目。
3. 若确有新机制，再添加参数明确的 `EffectDefinition` 和每次使用独立的 `EffectRuntime`。`Bind` 只注册回调；宿主默认按 UseId 过滤。
4. 修改待提交伤害/概率用 Hook；改变战斗状态通过事件响应 `yield return` 动作。不要从回调调用 `Execute`、`Use`、`PlayRound` 或 `DeclareDraw`。
5. 子动作后的判断写在 `yield return` 后，读取已完成的结果。不要提前 `ToList()` 枚举整个触发，也不要把标准攻击包装成每个技能都要配置的效果。
6. 持续状态创建独立宿主，补上刷新、到期和终局清理测试。普通技能结束不能注销其他使用或持续状态的规则。

效果优先级降序、注册顺序升序；条件在轮到当前候选时检查。宿主的 Active 与 Enabled 分离。效果是可信的 C# 扩展，Hook 的只读状态约定不是安全沙箱；公共状态写口仍限制在内核，公共结算入口禁止重入。
