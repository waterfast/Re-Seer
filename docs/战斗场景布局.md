# 战斗场景布局

继续在 `Assets/Scenes/Battle.unity` 编辑，Game 视图使用 16:9。

UI 只组合已有 Prefab：上方的双方 `HpBar`，下方的 `MainActionPanel`。

`MainActionPanel` 直接使用用户当前版本，保留其中原有的第五技能、右侧按钮和空技能容器。装配工具只调整整个面板的位置和等比缩放，不另行生成技能槽或按钮，不加载示例技能，不添加信号连接。

上一版额外装配的回合牌、倒计时、提示、待命头像及重复操作组件已移除。背景和两张精灵战斗图保留。

整理入口：`Tools/ReSeer/使用现有 Prefab 整理 Battle`。仅编辑器装配工具为 `Assets/Editor/BattleSceneComposer.cs`，截图为 `docs/screenshots/battle-layout.png`。不修改基础 Prefab 或现有运行时控制脚本。
