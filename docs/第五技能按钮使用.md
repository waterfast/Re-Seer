# 第五技能按钮：先用起来

新增脚本不声明 namespace。已有 SkillButton 和技能数据库暂时沿用原来的分组，不做项目级重写。namespace 只是类名的分组和重名隔离，跟按钮能不能运行、是否使用数据驱动没有必然关系。

## 使用你原来的预制体

当前使用 `Assets/Prefabs/BattleUI/Fifth Skill Button.prefab`。保留你摆好的 MainUi、Border、Information 等对象，在原有中心补上橙色三态底板和三个动态文字对象：Skill Name、Skill Power、Skill PP。

- 根对象挂 FifthSkillButton，继承现有普通 SkillButton。
- Inspector 的 `Custom Name` 可输入任意中文，支持换行。留空时显示 `Skill Name`；接入资料后显示 SkillData 的名称。
- `Custom Name` 只是按钮外观，不修改资料。后续 Bind 不会覆盖这个自定义名称。
- `Use Original Name Artwork` 默认关闭；打开且没有自定义名称时，才使用匹配的原版名称图片。
- 预制体显示的 200、2/10 是外观样例。当前没有开启进入运行模式后自动覆盖名称的演示资料绑定。
- 放入战斗场景后，点击需要已有 EventSystem 和摄像机上的 Physics2DRaycaster。

菜单 `Tools → Re-Seer → 补齐现有第五技能按钮` 用于补齐此预制体。另一个 Ready 预制体仅保留作旧示例。

## SkillData 是什么

当前项目已经有一个技能数据库：`Assets/Game Data/SkillDatabase.asset`。每条 SkillData 就是一条技能资料，包含 ID、中文名、威力、PP 上限、单次 PP 消耗、图标和说明等。它不是单独一个 .asset，也不需要现在再新建一个 SkillData 类。

按钮读取这条资料；剩余 PP 则单独传入。

```csharp
// database 和 fifthButton 通过 Inspector 指定。
if (database.TryGet("demo_thunder", out var skill))
{
    fifthButton.Bind(skill, 3); // 当前剩余 3 PP，而不是自动恢复满 PP。
}
```

上层监听选择：

```csharp
fifthButton.SkillSelected += OnSkillSelected;

void OnSkillSelected(ReSeer.Skills.SkillData skill)
{
    Debug.Log("选择技能：" + skill.DisplayName());
    // 下一步在这里提交给战斗控制层。
}
```

组件退出时配对解绑 `fifthButton.SkillSelected -= OnSkillSelected`。当前是按钮与技能资料的运行闭环，没有在这个按钮中接伤害结算。

确认新的 PP 后使用 `fifthButton.SetCurrentPP(2)`。普通按钮同样支持 `Bind(skill, remainingPP)`。Bind 默认关闭本地点击扣 PP，避免按钮自己改变战斗资源。

## 名称、字体和橙色边界

检查官方战斗 Flash 的实际标签后：

- 第五技能 PP 的两个文本对象 443/444 指向字体 276；字体名为 Arial Bold，黄色 #ffff00，12px。包中还有宋体、黑体、Arial Black 等其他字体，不能据此认定中央中文名称使用了其中某款。
- 中央 nameMc 是 469 号影片剪辑；首帧引用 447/449，继续追踪得到 DefineShape3/4。名称已转为矢量轮廓，没有字体引用，无法从该发布包确定原设计字体名称。
- 可自定义中文名称采用思源黑体 Heavy（不是已确认的官方字体），搭配倾斜、黄色字面和橙色描边，作为近似效果。可直接替换 Skill Name 的 TMP 字体与材质继续调。
- 官方橙色中心来自 clickIcon 381，位于 `Parts/center-button-up/over/down/hittest.png`，保留原按钮三态。

字体来源：[Adobe Source Han Sans](https://github.com/adobe-fonts/source-han-sans)，沿用同目录 SIL OFL 许可证。官方字体标签调查见 `docs/OfficialReference/20261001/fifth-skill-font-evidence.json`。

```csharp
fifthButton.Bind(skill, 3);
fifthButton.SetCustomName("自定义\n第五技能");
fifthButton.SetCustomName(""); // 恢复资料名称
```

## 脚本和验证

`FifthSkillButton.cs` 继承现有 SkillButton，新增名称图片、光圈播放、橙色按钮三态；数据库绑定、PP 和点击接口复用父类。

`SkillPanel.cs` 原来引用不存在的 SkillButtonUI 和未导入的 SkillData，现已接到真实类型。类名改为 SkillPanel，与文件名一致；显示技能时需要同长度的当前 PP 列表，避免显示时擅自恢复满 PP。

原预制体的验证记录在 `Logs/fifth-skill-existing-verification.txt`，检查自定义名称在 Bind 后保留、清空后恢复资料名称、点击不消耗 PP。预览见 `docs/screenshots/fifth-skill-existing.png`。
