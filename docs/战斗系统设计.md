# 战斗页面结构

当前范围是客户端战斗页面，职责与数据边界见 [前后端边界](基础骨架与前后端边界.md)。

| 目录 | 用途 |
|---|---|
| `Assets/Scripts/Battle/UI` | 技能、血条、菜单、点击反馈和导航 |
| `Assets/Scripts/Battle/Data` | 服务端数据在页面中的显示状态 |
| `Assets/Scripts/Skills` | 技能展示库、翻译接口及编辑器 |
| `Assets/Scripts/Events` | 页面组件之间的操作事件 |
| `Assets/Scripts/Pets/Art` | 精灵图片索引与加载 |
| `Assets/Editor` | 场景、预制体装配和编辑器检查 |

页面通过事件提交选择，通信层收到服务器结果后更新显示数据并播放动画。通信尚未接入，现有预览不表示战斗规则已经实现。

制作页面时优先复用现有组件与预制体；需要新显示数据时按页面需求补充字段，不引入物种、养成或效果结算框架。
