# HPBar 按精灵编号更新

当前只提供组件函数和图片查找，不接入战斗 UI 总控、事件通知或自动换宠。

```csharp
// 直接传显示资料：同时更新头像、名字、等级和体力。
hpBar.BindPet("70", "雷伊", 100, 200, 300);

// 也可以直接传当前战斗 Pet。
var pet = new BattlePetState("70", "雷伊", new[] { "electric" }, 100, 200, 300);
hpBar.BindPet(pet);

// 只更新已经确认的体力；不修改 BattlePetState、不计算伤害。
hpBar.SetHealth(150, 300);
hpBar.ClearPet();
```

`BattlePetState` 自身保存 `Id`、`Name`、`Level`、`CurrentHp`、`MaxHp`；不依赖旧客户端 Pet 或物种类，不引用 Sprite。修改战斗 Pet 后，外部需要再次调用 HPBar 函数才更新显示。

图片处理集中在 `Assets/Scripts/Battle/Art/PetArtResources.cs`。默认目录是 `Assets/Art/Pet`：头像 `avatar/70.png`，原图 `pets/70.png`。已迁入 98 张头像、66 张原图，保留原 `.meta`、图片哈希和场景引用。

```csharp
Sprite avatar = PetArtResources.GetAvatar("70");
Sprite artwork = PetArtResources.GetArtwork("70");
PetArtResources.SetCustomDirectory(@"D:\MyPetArt");
PetArtResources.SetCustomDirectory(null); // 恢复默认
```

自定义根目录同样包含 `avatar/编号.png` 和 `pets/编号.png`。缺失、无法读取或损坏时回退默认资源，两边都没有则返回 null；HPBar 不会保留上一只精灵的头像。再次指定同一目录可以重新读取修改后的图片。切换资源目录只重读已按编号绑定的头像，保持名字、等级、体力和布局。

默认资源自动生成 `Assets/Resources/PetArtCatalog.asset` 并随客户端打包，运行时不访问官网。资源目录内的 PNG 自动按 Single Sprite、100 Pixels Per Unit 导入。自定义目录目前支持本地文件系统，玩家目录选择界面与 WebGL 文件导入以后再做。

原来直接传 Sprite 的 `Bind` 入口仍保留。`HpBarTest` 的测试菜单改为通过编号 4500 绑定头像；不自动覆盖场景显示。整体战斗 UI 控制待界面完成后再接入。
