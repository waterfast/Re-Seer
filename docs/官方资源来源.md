## 可核对的来源链

1. `docs/OfficialReference/seer-home.html` 保存官网入口，`h5-index.html` 保存 WebGL 加载页。
2. 启动版本文件为 [version.js](https://h5-seer.61.com/TemplateData/version.js)，页面版本为 1.1.0。公开启动数据位于 [seer.data.gz](https://h5-seer.61.com/Build/seer.data.gz?v=1.0.0)。其中 AppConfig 声明正式 CDN 为 `https://newseer.61.com/Assets/`。
3. [主包版本清单](https://newseer.61.com/Assets/WebGL/DefaultPackage/PackageManifest_DefaultPackage.version)在采集时返回 `20260904173604`；对应[二进制资源清单](https://newseer.61.com/Assets/WebGL/DefaultPackage/PackageManifest_DefaultPackage_20260904173604.bytes)已保存，可按资源路径核对包索引和 MD5。
4. 本地只解码资源，不加载官方组件或执行包内代码。没有登录、调用战斗服务器或下载全部资源包。

## 缓存与复现

采集缓存位于 `docs/OfficialReference`。早期探查的 Flash 启动文件、特训背景候选和 WebGL 启动数据也保留在该目录；运行场景除上表图片外，还引用下节列出的原版 UI、头像和字形。候选 `gaiya_special_training_fightbg` 自带特训文字，已舍弃；`battle_test_machine_combat_test_bg0` 和 `fight_lab_1_bg` 未接入。

提取器为 `tools/extract_official_art.py`。开发时将 UnityPy 1.25.3 安装到临时目录 `Temp/AssetTools`，运行提取器即可从已保存的资源包重建立绘、头像 PNG 和来源记录。它不主动联网；Unity 的运行与核心测试也不需要 Python。

官网资源版权归原权利人，此处用于本地学习与同人原型验证；抓取不等于获得对外发布或商业使用授权。UI 中的魂印与战斗数值使用本项目规则，不能从图片来源推导为官方规则。

## 2026-09-09：Flash 面板、属性与伤害数字

本轮重排采用 Flash 原始装饰元件。官网 `RobotAppDLL.swf` 的 `FightNoteCmdListener` 通过 `ClientConfig.getDLLPath` 加载 [PetFightDLL_201308.swf](https://seer.61.com/dll/PetFightDLL_201308.swf)。静态解压、解析后提取 DefineShape 1640/1647（技能底板与悬停）、476（头像血条框）、624（底栏）、358（第五技能圆盘）。JPEXS 26.2.1 以三倍比例光栅化原始矢量，未带入文字、占位技能名或 ActionScript。文件名后缀不作为版本日期。具体 SHA-256 见 `Assets/Art/Battle/Flash/sources.json`。

Unity 端补充：

- [属性图集包](https://newseer.61.com/Assets/WebGL/DefaultPackage/53ee4cf1e8320361c4aa9b7114c1fffa)：`PetType.spriteatlas`，Sprite 5 / 8 / 11，对应电 / 普通 / 战斗；编号与官网精灵 XML 双重核对。
- [字体包](https://newseer.61.com/Assets/WebGL/DefaultPackage/e6ae1b6a24e07173fddd3e9af2475c7e)：`hp_damage_num` 位图字体和 `hp_damage_num_0` 图集，按官方 CharacterRects 的 UV 提取减号与十个数字，保留透明度，不是替代系统字体。
- [雷伊头像包](https://newseer.61.com/Assets/WebGL/DefaultPackage/1400be6cc627e9577df0496cbaa52a90)、[盖亚头像包](https://newseer.61.com/Assets/WebGL/DefaultPackage/8e3841f3ba204c666887a058c1d0d176)：原路径 `Assets/Art/Ui/assets/pet/head/70.png`、`261.png`。
- 原战斗 UI 包的 `battle_blood` 用于血量填充，`battle_round_bg` 用于回合标记；其他导出的底板保留在 `UI/` 作为比较参考。

`tools/extract_battle_ui.py` 与 `tools/extract_flash_ui.py` 可从本地缓存重复提取。本轮没有登录正式服，参考为公开资源及面板结构，静态首帧截图不等同于正式服实战画面。布局取舍与装配入口见 [战斗 UI 参考与装配](战斗UI参考与装配.md)。
