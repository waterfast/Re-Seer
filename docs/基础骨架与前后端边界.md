# 客户端战斗页面与前后端边界

当前项目只制作客户端战斗页面。

客户端负责：

- 展示双方精灵、头像、立绘、HP、技能 PP、状态、道具和回合信息。
- 管理菜单切换、点击反馈、输入锁定、等待服务器与动画播放。
- 将玩家选择通过事件交给后续通信层，并用服务器确认的数据刷新界面。
- 根据技能 ID 查询本地展示资料，翻译技能名称和描述。

服务端负责伤害、命中、行动顺序、效果、状态变化、PP 消耗、换人合法性及胜负判定。客户端不维护物种学习表、养成公式、刻印规则或战斗结算器。

`Assets/Scripts/Battle/Data/` 是页面数据容器；HP、PP 等设置接口用于同步已确认数据或编辑器预览。界面状态机只控制导航与等待，不推进战斗回合。

`SkillButton.Bind(...)` 绑定技能资料与当前 PP；`SetInteractable(...)` 接收外部可用状态。点击只广播操作意图，不改变 HP 或 PP。后续收到服务端数据后调用 `SetPP(...)` 或重新绑定。

技能库保留效果列表、效果参数、目标、PP 消耗和先制等数据，以及服务器 JSON 导出，供后续描述翻译与服务器数据库使用；客户端不执行这些规则。

技能库保留 `nameKey`、`descriptionKey`、回退文案和 `DisplayName(translate)` / `Describe(translate)`。翻译缺失时使用回退文案；翻译服务由调用方提供。属性、类别、威力、命中率和最大 PP 用于显示，不用于本地结算。

精灵素材编号只用于查询图片。页面无需创建 `PetSpecies` 或完整养成个体才能显示一只精灵。
