# 技能数据库

当前数据流程、版本字段用途和已知缺口见[技能数据审查](技能数据审查.md)。

唯一编辑源是 `Assets/Game Data/SkillDatabase.asset`。它是一个 `SkillDatabaseSO`，其中每项 `SkillData` 是内嵌的可序列化记录，不是单独的 ScriptableObject。四条 `demo_*` 记录仅用于编辑流程验证，数值不是官方资料。

在 Unity 菜单 `Tools > Re-Seer > Skill Editor` 打开 UI Toolkit 窗口，可以新增、删除、搜索、编辑技能记录。`保存数据库` 会先检查 ID、数值和效果字段。`导出服务器 JSON` 写到 `GameContent/Generated/Server/skills.json`，仅含规则相关字段；图标、中文文案、翻译 key 和表现资源 key 留在客户端数据库。服务器现在没有接入，JSON 只是后续交换格式。

新增技能时填写稳定 `id`、属性、类别、威力、命中率、PP、目标、效果列表及中文回退文案。`nameKey` 与 `descriptionKey` 是翻译接口预留；`DisplayName(translate)` 和 `Describe(translate)` 接受翻译函数，缺失翻译时显示回退文案。效果参数当前仍是通用 key/value 记录，客户端不执行这些效果，也没有参数专用编辑控件。

运行时当前 PP 不存入数据库，后续由战斗快照提供。旧 `SkillButton.prefab` 是独立的测试按钮，尚未接到这套新界面；手工接线时用数据库的 `id` 读取静态显示数据，用服务器确认的快照刷新 PP。`Tools > Re-Seer > Verify Skill Database` 检查数据库与 JSON 投影。
