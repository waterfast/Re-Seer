# Flash 页游战斗界面对照

来源：7k7k《赛尔号咤克斯解析》，发布于 2015-02-09。
文章：https://news.7k7k.com/51seer/20150209-701630.html
原图：http://n.7k7kimg.cn/2015/0209/1423453019801.jpg
本地图片：seer-flash-2015-battle.jpg

这是当年的实战截图，原图仅 500 × 288，带 7k7k 水印。保留原图；不把放大图当成高清原件。
对照本项目 docs/screenshots/battle-layout.png（文件修改时间 2026-10-07）及 main-action-panel-skills.png。

对应样式：蓝色机械血条、左下第五技能盘、底部横排普通技能、右下捕捉/道具/战斗/精灵/撤退五向按钮。

优先核对：
- 普通技能选择状态是否完整显示四个技能槽，避免只对照菜单未展开时的空底栏。
- 上方中央的回合/对战提示、血条附近的属性与状态信息。
- 姓名、等级和血量的相对位置；右侧装饰 HP 字样不应随整张边框镜像后反向。
- 普通技能卡默认态与悬停态需要分别比对。参考截图默认卡片较暗，项目已有截图使用亮青蓝底板。
- 第五技能盘与底栏的尺寸比例、人物站位和底部空间。

仅完成参考图收集和静态比对，没有修改场景或代码；未通过 Unity 实时截图确认当前运行状态。
