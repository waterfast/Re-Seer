名称描述来自本次目视检查，不代表已经确定其官方元件名称或玩法功能。1373/1377/1381 是同类电光图，尚未核实它们在 SWF 时间轴上的先后顺序。总览图仅供挑选，游戏使用单张 PNG。

`sources.json` 保存源网址、下载日期、原包 SHA-256、CharacterId、SWF 标签、图片尺寸和 PNG SHA-256。原包保存在项目 `docs/OfficialReference/PetFightDLL_20260909.swf`。它与此前下载的同名模块内容哈希是否一致，应以清单实际值为准；模块名里的 201308 不当作内容日期。

提取方法：按官方包装跳过 7 字节并 zlib 解压，展开 SWF 标签；解码 DefineBitsJPEG2/3 与 DefineBitsLossless/2 的直接位图，JPEG3 合并独立 Alpha；Lossless2 的预乘透明颜色转回普通 RGBA。此次没有渲染矢量形状、拼装 MovieClip 或推断骨骼动画。
